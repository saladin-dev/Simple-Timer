# ⏱️ Simple Timer (Python)

A basic Python script that pauses execution for a specified number of seconds.  
This project was created to explore the use of Python's `time` module and user input.

---

## 🎮 What It Does

- Prompts the user to input a number of seconds.
- Converts the input to an integer.
- Waits for the specified duration using `time.sleep()`.
- Prints a message once the timer finishes.

---

## 🧠 Features

- Demonstrates use of the `time` module.
- Interactive user input with `input()`.
- Clean and simple control flow using `sleep()`.

---

## 🛠 Technologies Used

- **Python 3**
- Built-in `time` module

---

## 📌 Future Improvements
